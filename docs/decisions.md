# Lorebook: согласованные решения (опрос 13.10.2026)

## Цель
- Главная цель: проект для портфолио. Публичный пример на Python с LangChain/LangGraph и RAG по книге. При споре «больше функций или лучше код» выбираем код.
- Вторая цель: полезный сервис для иллюстраторов, контент-мейкеров и писателей.
- Пользователь один (вы). Регистрации и учётных записей нет.

## Платформа и техника
- От Abacus отвязываемся полностью.
- Бэкенд: Python, FastAPI, LangChain, LangGraph. База: PostgreSQL + pgvector. Интерфейс: React.
- Запуск локально одной командой через Docker, с возможностью без переделок залить на хостинг.
- Локально вход без пароля; на хостинге один общий пароль из настроек запуска.
- Что берём из MVP от десктопного Claude, решаем после того, как вы его покажете.

## Подключение нейросетей
- Подключение задаётся парой «адрес + ключ» (OpenAI-совместимый формат), подключений может быть несколько: OmniRoute (бесплатные модели) и OpenRouter (платные).
- После вставки ключа подгружается список моделей, есть фильтр «только бесплатные».
- Модель для текста и модель для картинок выбираются отдельно.
- Ключи хранятся на сервере в зашифрованном виде, в интерфейсе видны только последние 4 символа.
- Проверить при сборке: умеет ли OmniRoute отдавать картинки.

## Два режима проекта
- При создании проекта выбор: «пишу книгу» или «работаю с готовой книгой».
- «Готовая книга»: только режим иллюстратора, текст не редактируется, перейти в режим писателя нельзя.
- «Пишу книгу»: переключение между режимами писателя и иллюстратора в обе стороны.

## Импорт и главы
- Форматы: TXT, EPUB, FB2, DOCX, PDF с текстом. Сканы и загрузка по ссылке не входят в первую версию.
- Импорт = только разбивка на главы, без ИИ и без токенов: по оглавлению файла и заголовкам.
- Если глав нет: нарезка по объёму, плюс кнопка «Разбить по смыслу с ИИ».
- Границы глав можно править руками (объединить, разделить).

## Персонажи и локации
- Ничего не ищется автоматически. Отдельные кнопки «Найти персонажей» и «Найти локации и предметы».
- Перед запуском: выбор глав (по умолчанию вся книга) и оценка расхода токенов.
- Обход по главам с видимым прогрессом, сохранение после каждой главы, продолжение с места обрыва.
- Новые главы дополняют существующие карточки, дубли не создаются.
- Карточка только для чтения: постоянные черты + лента изменений по главам + цитаты-источники из текста.
- Найденные без имени (Стары, дзяўчына) и группы (купцы, вартавы) показываются отдельно, в разделе «Под вопросом» со знаком «?»: скорее всего, это уже известные герои; пользователь объединяет их вручную. Если какая-то глава называет имя, карточка переходит в основной список (Александр, 10.11.2026).
- У всех карточек одно «Общее описание»: его пишет ИИ в конце поиска, а карандашом его можно переписать своим текстом. Свой текст поиск не затирает; если его стереть, вернётся текст ИИ. Ручная карточка создаётся одной формой: имя и общее описание (Александр, 10.11.2026).
- В «Персонажах» только живые и одушевлённые (люди, звери, духи, говорящие существа). Важные неодушевлённые вещи (оружие, артефакты, мосты, мельницы) ищутся вместе с местами в разделе «Локации и предметы»; то, что персонаж носит, по-прежнему пишется и в его ленту (Александр, 10.11.2026).
- В окне поиска выбор: «Добавить к найденному» (прочитанные главы не читаются повторно) или «Пересканировать с нуля» (прежние ответы модели и карточки забываются; карточки с картинками, ручными объединениями и разделениями и созданные вручную остаются, но теряют факты).
- Править данные можно двумя путями: в промпте или в самом тексте книги (режим писателя).

## Стиль и картинки
- Стиль один на весь проект, выбирается из готового списка или задаётся своим описанием.
- Каждая картинка помечена стилем, в котором сделана. В референсы предлагаются только картинки текущего стиля. После смены стиля картинки создаются заново, старые не удаляются.
- Галерея персонажа и локации: загруженные референсы и сгенерированные в сервисе.
- Основных картинок может быть сколько угодно: это набор ракурсов, задающих лицо и фигуру (лицо анфас и в профиль, рост спереди, сбоку, сзади). Ракурс выбирается перед генерацией или под картинкой; если не выбран, сервис берёт первый недостающий.
- Первая основная рисуется с нуля, все следующие картинки (основные и облики) — от уже готовых основных, чтобы лицо совпадало.
- Остальные картинки — облики. Облик привязывается к одной главе или ни к какой; диапазон «с главы по главу» убран по решению владельца 15.10.2026.
- В сцену сервис сам подставляет лучшее лицо и лучший рост из основных и облик по главе.

## Сцены
- Два способа: кнопка «Разбить на сцены» в главе (ИИ делит и помечает яркие) и ручное выделение текста в читалке.
- Сцена хранит границы в тексте, участников и локацию; сама не редактируется.
- Кнопка «Собрать промпт для видео»: сервис сам берёт участников, их облик на эту главу, локацию и стиль.
- Промпт правится руками; есть поле для правок словами. Хранится только последняя версия промпта.
- Кнопка «Сгенерировать кадр»: стартовый кадр сцены в стиле проекта.
- «Скопировать промпт» и «Скачать референсы» одним архивом с подписанными файлами, кадр входит в архив.
- Видео в первой версии не генерируется. Формат промпта пока один, универсальный.

## Режим писателя
- Старт с нуля или с загрузки черновика. Главы создаются, переименовываются, переставляются, удаляются.
- Редактор простой: текст, абзацы, курсив, жирный.
- Версия одна на всю книгу: правки в любых главах, затем одна кнопка «зафиксировать». Откат к любой версии.
- После новой версии ничего не пересчитывается само. «Устарело» помечается только то, что зависит от изменённых глав; кнопка «Обновить» пересчитывает только их.
- При откате правило то же: сравнивается текст главы с тем, по которому считались данные.
- Картинки не удаляются никогда.

## Чат по книге
- Боковая панель, доступен в обоих режимах, знает открытую главу.
- Отвечает только по тексту, с цитатами и переходом к месту в главе. Если ответа в книге нет, так и говорит.
- В режиме писателя: «предложи развитие событий» даёт 3 коротких варианта, в текст ничего не вставляет.
- Переписка сохраняется в проекте. Чатов у книги несколько (10.11.2026, просьба Александра): «Новый чат» начинает разговор с чистого листа, старые выбираются из списка; агент видит историю только своего чата. Название — по первому вопросу, меняется в настройках чата.
- У каждого чата в настройках «Где искать»: по умолчанию вся книга, либо отмеченные главы — тогда поиск и чтение только в них (в оглавлении агента только они). Старая переписка проекта стала его первым чатом (миграция 0009).

## Интерфейс
- Тёмный, спокойный, в духе программ для монтажа. Слева главы, в центре текст, справа чат.
- Разделы: Книга, Персонажи, Локации, Сцены, Настройки. Раздела «Visual Canon» нет.
- Поиск по тексту; имена персонажей и локаций подсвечены, по клику открывается карточка.
- Языки интерфейса: русский и английский. Карточки и чат на языке книги. Промпты для видео и картинок всегда на английском.
- Цвета и шрифты (14.10.2026): по стилю «Тёмный / Violet» из библиотеки «Архитектора сайтов», фиолетовый акцент заменён жёлтым. Шрифт системный (Segoe UI), размеры из шаблона: текст 16, текст книги 18, заголовки 34 жирные.
